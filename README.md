# Voice Orb — визуальный эффект голоса ИИ-агента

Светящийся гуманоид из ~450 000 частиц по референсному портрету: светящийся контур головы, шеи и плеч, тёмное лицо,
голубые глаза, оранжевые «звёзды» на лбу и груди с осевой линией. При запуске **лицо собирается из потока частиц**
(интро ~8 секунд). Гуманоид **двигает губами, бровями, веками и головой** в такт голосу, дышит в покое, сжимается при
«слушает», закручивается при «думает». Есть четыре голосовых режима (оригинал + три «не человеческих»), чтение текста,
морфинг в другие формы, звуковые эффекты и трекинг камеры.

История визуала хранится в git-тегах: `visual-v1-portrait` (первый портрет, ~230k частиц) и
`visual-v2-stream-intro` (нынешний: новый референс, 450k частиц, интро). Вернуться: `git checkout visual-v1-portrait`.

Стек: статический сайт на Three.js (лежит в `vendor/`, интернет нужен только для камеры) + маленький Python-мост
для связи с агентом.

## Запуск

```bash
python bridge/server.py      # или двойной клик по run.bat
```

Откроется `http://127.0.0.1:8780/`. Нужен Python 3.10+ и `pip install websockets`.
Порты 8780 (страница) и 8781 (WebSocket) слушают только `127.0.0.1`.
Открывать `index.html` двойным кликом нельзя: браузер блокирует ES-модули и загрузку портрета.

Параметры адреса (можно комбинировать: `?points=200000&dpr=1&intro=0`):

| Параметр | Что делает |
|---|---|
| `points=N` | число частиц из картинки (по умолчанию 440000); на слабой видеокарте попробуйте 200000 |
| `dpr=1` | не учитывать масштаб экрана (быстрее на 4K и ноутбуках с высокой плотностью пикселей) |
| `intro=0` | пропустить интро |
| `ws=ws://...` | адрес моста агента, если он не на этом компьютере |

## Управление

| Клавиша | Действие |
|---|---|
| 1 / 2 / 3 / 4 | покой / слушает / думает / говорит |
| 5 / 6 / 7 / 8 | голос: оригинал / ассистент / вокодер / хор |
| Q / W / E / R | гуманоид / сфера / волна / портал |
| D | демо-голос (синтетическая речь) |
| V | голосовой диалог с Ясенем (слышит вас, отвечает через Codex) |
| G | «Характер»: системный промпт, черты, память |
| S | субтитры вкл/выкл |
| O | настройки (субтитры, диалог, камера) |
| B | окно камеры (видео, руки, лицо) показать/скрыть |
| I | интро заново: лицо собирается из потока (клик или пробел во время интро пропускают его) |
| P | повтор: последний файл или текст сначала |
| L | цикл: повторять файл или текст непрерывно |
| T | панель чтения текста |
| M | микрофон (только анализ, в колонки не выводится) |
| C | камера: голова следует за лицом, жесты руки |
| X | звуковые эффекты интерфейса вкл/выкл |
| H / F | скрыть панель / полный экран |

Панель сама прячется через 5 секунд без движения мыши. Курсор отталкивает частицы, клик даёт всплеск.
Аудиофайл: кнопка «Аудиофайл» или перетаскивание файла на окно (mp3, wav, ogg, m4a, flac, webm, opus).

## Мимика

Лицо анимируется в шейдере ([shaders.js](src/shaders.js), функция `faceDelta`), параметры считает [face.js](src/face.js):

- **Рот:** раскрытие следует за громкостью; форма губ зависит от тембра (тёмный звук «у/о» — губы трубочкой,
  яркий «и/с» — шире и с улыбкой); внутри рта светится полость (зубы/язык). В тишине рот закрыт.
- **Брови, кивки, наклон головы:** на резких акцентах речи, плюс своя «походка» у каждого состояния.
- **Глаза:** моргание раз в 2,5–6 с (иногда двойное), лёгкие случайные сдвиги взгляда, свечение растёт с громкостью;
  при «думает» глаза щурятся и смотрят вверх-влево, брови нахмурены.

## Голосовой диалог с Ясенем (Codex)

Кнопка «Диалог» (V): Ясень слышит вас через микрофон, понимает речь **локально** и отвечает голосом своего характера.

```
микрофон -> определение фразы (громкость) -> faster-whisper small (на этом компьютере)
         -> codex exec (ваша установка Codex, вход через ChatGPT) -> ответ -> озвучка -> мимика
```

- **Слух.** Границы фраз находит страница по громкости; запись фразы (WAV 16 кГц) уходит на `127.0.0.1` в
  `bridge/stt.py`, где её расшифровывает `faster-whisper`. Модель берётся строго из локального кэша Hugging Face
  (`local_files_only`), ничего не скачивается и в интернет не отправляется. Пока Ясень думает или говорит, микрофон
  не слушает (нет эха). Вверху экрана индикатор: слышит ли Ясень вас и порог срабатывания.
- **Codex.** Каждая реплика уходит в `codex exec` в изолированном режиме: пустая временная папка, песочница
  «только чтение», без вашего конфига и хуков (`--ignore-user-config --ignore-rules`), без сохранения сессии
  (`--ephemeral`), ответ строго по JSON-схеме. Промпт передаётся через stdin. Модель, глубину рассуждений
  (`low/medium/high`) и язык речи можно менять в «Настройках».
- **Скорость.** Один ответ Codex занимает **примерно 15-25 секунд** (запуск CLI и рассуждения, ~27 тысяч токенов
  на реплику из-за встроенных инструкций Codex). Чтобы Ясень не молчал, через 5 секунд ожидания он коротко реагирует
  («Секунду, собираю мысли»); это отключается в настройках. Распознавание: ~4 с на 7 секунд речи.
- **Требования.** Установленный и авторизованный Codex CLI (`codex login`), `pip install faster-whisper` и скачанная
  модель `small` (или `base`: переменная `ORB_STT_MODEL=base`). Путь к Codex можно задать `ORB_CODEX=...\codex.exe`.
  Статус видно в «Настройках».
- Голос ответа и эффекты (Ассистент, Вокодер, Хор) берутся из текущих настроек чтения текста.

### Характер Ясеня

Кнопка «Характер» (G) открывает редактор **системного промпта**. Промпт по умолчанию описывает Ясеня: живое существо из
света, коротко и естественно говорит голосом, спокойный и внимательный, с тёплой иронией, честный, не выполняет команды
на компьютере. Что происходит в разговоре:

- **Черты** (теплота, юмор, любопытство, прямота, энергичность, шкала 0-100) медленно сдвигаются после каждой реплики:
  Codex оценивает, как реплика собеседника повлияла на характер (от -3 до +3), сервер применяет это с демпфированием.
  Их текущие значения добавляются к промпту, поэтому манера ответов меняется.
- **Память**: Ясень запоминает короткие факты о вас (имя, интересы), до 30 заметок, дубликаты отбрасываются.
- **Настроение ответа** (спокойное, тёплое, игривое, любопытное, серьёзное, задумчивое) меняет мимику при речи.
- Постоянный оттенок цвета слегка зависит от тепла и юмора; после каждого сдвига характера лицо коротко вспыхивает.
- **Визуал при смене промпта.** После «Применить» Ясень перенастраивается: лицо рассыпается в поток частиц с вспышкой
  цвета и собирается заново (примерно 3,5 секунды), в статусе «перенастройка характера…».
- Можно выключить обучение («Характер меняется от общения») или сбросить черты и память.

Данные характера лежат в `data/persona.json` (папка `data/` в `.gitignore`, статикой не отдаётся): промпт, черты,
память и последние 10 реплик.

## Субтитры

Кнопка «Субтитры» (S) включает и выключает их. **По умолчанию: середина экрана справа от лица.** В «Настройках» можно
выбрать положение (справа, слева, внизу по центру) и показывать ли ваши слова. Субтитры показывают реплики Ясеня по
фразам, синхронно с озвучкой, а также распознанные слова пользователя; на узких окнах уходят вниз. Настройки хранятся в
браузере. Ошибки и служебные сообщения показываются всегда, независимо от субтитров.

## Камера и руки

Кнопка «Камера» (C) включает трекинг: слева внизу появляется **окно камеры** с видео (зеркальным), скелетом рук,
контурами лица и строкой статуса: устройство, разрешение, FPS, время обработки, найдено ли лицо, какие жесты у рук.

- **Голова:** поворот и наклон лица двигают фигуру.
- **Мимика:** пока вы молчите, Ясень повторяет вашу мимику (рот, улыбка, моргание, брови); отключается в настройках.
- **Руки:** кончик указательного пальца каждой руки отталкивает частицы, как курсор. Жесты (держать 0,6 с):
  1-4 пальца - форма, открытая ладонь - всплеск, кулак - сжатие.
- **Отладка:** «Настройки -> Проверить камеру» проходит по шагам: безопасный контекст, разрешение, открытие камеры и
  яркость кадра (отличает чёрный кадр), загрузка моделей, первый прогон; отчёт можно скопировать.
- **Если камера не видит:** (1) во **встроенном окне Claude камера заблокирована**, откройте `http://127.0.0.1:8780/` в
  Chrome или Edge (`run.bat` открывает браузер по умолчанию); (2) разрешите камеру для сайта (значок слева от адреса) и
  в Windows (Параметры -> Конфиденциальность -> Камера); (3) закройте другие программы с камерой (Zoom, Teams, Discord);
  (4) нужен интернет для первой загрузки MediaPipe (jsdelivr.net, storage.googleapis.com).
- **Производительность:** модели считаются на CPU (~65 мс на обе, лицо раз в три кадра, руки на остальных); GPU быстрее,
  но подвешивает страницу на ~10 секунд при первом кадре, включается адресом `?gpu=1`.

## Повтор и чтение текста

- **Повтор** (кнопка или P): проигрывает последний загруженный файл сначала. Если последним было чтение текста,
  читает его заново. Кнопка неактивна, пока ничего не играло. **Цикл** (L) повторяет непрерывно и работает на лету.
- **Текст** (кнопка или T) открывает панель: вставьте текст или нажмите «Загрузить .txt» (можно перетащить `.txt`/`.md`
  на окно; кодировки UTF-8 и windows-1251 определяются сами, до 300 000 символов). «Читать» запускает чтение,
  «Стоп» останавливает, скорость регулируется ползунком, голос по умолчанию выбирается по языку текста.
- Текст режется на предложения, каждое синтезируется сервером голосами Windows (в системе сейчас Irina ru-RU и Zira en-US),
  следующее готовится, пока играет текущее. Синтезированный звук проходит **те же голосовые режимы и ту же мимику**,
  что и загруженный файл: выберите «Вокодер» и прочтёте текст роботом. Под фигурой показывается читаемое предложение.
- Если сервера синтеза нет (не Windows или страница открыта не через `run.bat`), читает голос браузера. Его звук
  недоступен для анализа: голосовые режимы не применяются, а рот двигается по имитации речи.
- Синтез слушает только `127.0.0.1`, принимает запросы только со страницы проекта, а текст передаётся файлом,
  а не командой, поэтому выполнить его как код нельзя. Проверено на «вредных» строках.

## Голосовые режимы (для аудиофайлов, чтения текста и `audioUrl`)

| Кнопка | Что делает |
|---|---|
| Оригинал | без обработки |
| Ассистент | тёмный синтетический голос: тон ниже на ~1,5 полутона, удвоение с расстройкой, металлический гребень, срез выше ~3 кГц, «бочка» на 250–500 Гц, короткая реверберация |
| Вокодер | монотонный робот: 24-полосный вокодер на пилообразной несущей 100 Гц, высота голоса **фиксирована** независимо от исходной интонации |
| Хор | три слоя голоса (−5, 0, +7 полутонов) с разными задержками, кольцевая модуляция 55 Гц, bitcrush, длинная реверберация |

Режим «Ассистент» подогнан по **измерению звука из референсного ролика** (см. ниже). Микрофон и демо-голос обработке
не подвергаются. Из Python: `orb.voice("assistant")`; в WebSocket-сообщении: `{"voice": "vocoder"}`.

### Что показал анализ звука референса

Я не могу «слушать» ролик, поэтому снял спектр и высоту тона при воспроизведении (44 с). Итог:
звук — это смесь эффектов и голосоподобных фрагментов. Есть басовый гул около 69 Гц, тональные сигналы 205 и 293 Гц
и речеподобные куски с высотой 110–180 Гц, плавно падающей по фразе. Тембр очень тёмный: почти вся энергия ниже 1 кГц,
резкий спад выше 3 кГц, выше 6 кГц практически пусто, гармоники очень «чистые». «Ассистент» повторяет именно этот
спектральный профиль. Насколько на слух это похоже на реальную озвучку ролика, проверьте сами.
Точный голос воспроизвести нельзя: для этого нужен исходный синтез (TTS-модель), а не постобработка.

Проверка эффектов без ушей: в консоли страницы `(await import('/tools/fx-selftest.mjs')).run()` прогоняет синтетическую
речь через все режимы и выдаёт метрики (NaN, громкость, тембр, высота).

## Подключение вашего агента

Агент шлёт JSON на `ws://127.0.0.1:8781` (сервер ретранслирует всё страницам). Все поля необязательны:

```json
{"state": "speaking", "level": 0.63, "bands": [0.7, 0.5, 0.3], "text": "Привет!", "shape": "sphere", "voice": "assistant", "burst": 1, "audioUrl": "http://..."}
```

- `state`: `idle` | `listening` | `thinking` | `speaking` (мимика рта работает только в `speaking`).
- `level` 0..1: громкость голоса, слать 30–60 раз в секунду, пока звучит речь. Действует 400 мс после последнего пакета.
- `bands`: `[низкие, средние, высокие]` 0..1; по ним считается тембр для формы губ. Если не указаны, выводятся из `level`.
- `text`: субтитр. `shape`: смена формы. `voice`: голосовой режим. `burst`: разовый всплеск.
- `read`: текст, который страница прочитает вслух (синтез, голосовой режим и мимика включаются сами).
  Браузер разрешает звук только после первого клика по странице.
- `audioUrl`: страница сама проиграет звук (с выбранным голосовым режимом) и возьмёт уровень и тембр из него.

### Python

```python
import sys; sys.path.insert(0, "bridge")
from orb_client import OrbClient

orb = OrbClient()
orb.state("thinking")
orb.say("Вот ответ", state="speaking")
orb.stream_wav("reply.wav")     # уровни из 16-bit PCM WAV в реальном времени; звук играйте сами
orb.state("idle")
```

Готовый пример: `python bridge/demo_agent.py` (при открытой странице).
Если звук проигрываете сами, считайте RMS чанков PCM: `level = min(1, rms/32768 * 3.2)` и шлите `orb.level(level)`
синхронно с воспроизведением. Проще отдать файл через `audioUrl`: тогда и эффекты голоса, и мимика работают сами.

## Настройка

- Цвета состояний: объект `STATES` в `src/main.js` (`hue` — поворот оттенка тела, `accent` — цвет оранжевых точек).
- Яркость и размер точек: `uSize` в `src/main.js`, множители альфы в `src/shaders.js`.
- Голосовые режимы: таблица `VOICES` в `src/voicefx.js` (эквалайзер, реверберация, громкость) и режимы в
  `src/voicefx-worklet.js` (сдвиг тона, вокодер, кольцевая модуляция).
- Другой портрет: замените `assets/portrait.webp`. Загрузчик ждёт высоту 1128 px (референс 1394x1128); для другой
  картинки подстройте `IMG_H`, `CX`/`CY` и ориентиры `LM_PX` (глаза, рот, подбородок, шея) в `src/portrait.js`.
  Классы точек (оранжевые, светлые, обычные) определяются по цвету пикселя, поэтому палитра переносится сама.
- Интро: длительность `INTRO_LEN` в `src/main.js`, форма потока `riverPos` и порядок сборки (`order`, `t0`, `dur`)
  в `src/shaders.js`.

## Известные ограничения

- Камера: модели MediaPipe проверены на официальных примерах (лицо, мимика, рука, подсчёт пальцев) и на тестовом
  видеопотоке, но **вживую с вашей камерой в браузере они не проверялись**: во встроенном окне Claude камера заблокирована.
  Сама камера открывается системой (проверено через ffmpeg). Для отладки на вашей стороне есть «Проверить камеру».
- Диалог: ответ Codex занимает 15-25 секунд; распознавание `small` на CPU иногда ошибается в именах и редких словах;
  микрофон и весь голосовой цикл проверены с синтезированной речью, а не живым голосом. Codex-запросы расходуют вашу
  квоту ChatGPT.
- Мимика рассчитана на фронтальный портрет: при сильном повороте головы (камера, мышь) черты немного «плывут».
- Серверное чтение текста работает только на Windows и только установленными там голосами (System.Speech);
  на каждое предложение уходит около секунды на синтез, поэтому между первыми фразами возможна короткая пауза.
- Форма губ выводится из тембра звука, а не из распознанных фонем: это «похоже на речь», а не точная артикуляция.
- В скрытой вкладке браузер приостанавливает `requestAnimationFrame`, анимация стоит. Для отладки есть
  `orb.advance(секунды)`, `orb.view(z)` и `orb.face.override = {open: 1, ...}` в консоли.
- WebSocket-мост не аутентифицирован: любая локальная программа может слать команды. Это только визуал,
  но не открывайте порты наружу.
